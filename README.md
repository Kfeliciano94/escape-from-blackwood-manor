# Escape from Blackwood Manor

A command-line horror adventure game written in Python for SNHU IT 140 coursework. Explore the manor, collect seven objects, and avoid Lady Blackwood until you are ready to confront her.

## Features
- Eight interconnected rooms
- Item collection and inventory tracking
- Win/lose conditions based on collected items
- Text commands for movement, collecting items, and exiting

## Run
Requires Python 3. From the project folder:

```bash
python Projecttwo.py
```

Enter commands such as `go North`, `get Candle`, or `exit`. Collect all seven items before entering the Haunted Basement.

## About
Developed as a student project for IT 140 – Introduction to Scripting at Southern New Hampshire University. The original game has been preserved with two bug fixes: the undefined win-condition variable and the missing Holy Relic in the required-items list.
